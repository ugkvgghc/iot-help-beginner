IoT Help Beginner

ผู้ช่วยแปล Bug ใน Arduino IDE เป็นภาษาคน พร้อมจำลองวงจรสไตล์กระดาษตัดแปะ (Paper-Scrapbook)

🚀 วิธีใช้งานร่วมกับโปรแกรม Arduino IDE แบบง่ายๆ (ทำตามได้ทันที!)

1

เปิด Arduino IDE แล้วเลือกไฟล์ `.ino`

เปิดโปรแกรม Arduino IDE ของคุณขึ้นมาตามปกติ แล้วกดปุ่ม "📂 เลือกไฟล์ .ino ในเครื่อง" ด้านล่าง เพื่อชี้เป้าไฟล์ที่คุณกำลังเขียนอยู่ (หรือปล่อยให้โปรแกรมตรวจจับไฟล์ล่าสุดให้อัตโนมัติ)

2

กดโหมด "📌 เกาะขอบจอ" แล้วเขียนโค้ดได้เลย

กดปุ่ม "📌 โหมดเกาะขอบจอคู่กับ Arduino IDE" หน้าต่างจะย่อเป็นตัวละครลอยอยู่มุมจอ เวลาคุณพิมพ์โค้ดใน Arduino IDE แล้วกด Save (Ctrl + S) โปรแกรมจะตรวจโค้ดให้ทันที!

3

ดูจุดผิด (?) บนวงจรกระดาษแปะ & กดแก้โค้ดอัตโนมัติ

ถ้าเขียนโค้ดผิด (เช่น pinMode(4, Output);) ตัวละครจะพูดบอกเป็นภาษาคน และชี้ว่าอุปกรณ์ชิ้นไหนในวงจรที่มีเครื่องหมาย ? บนหัว พร้อมปุ่มกดแก้โค้ดให้อัตโนมัติ!

กำลังซิงค์กับไฟล์ Arduino IDE: blink_bug.ino
