🚀 วิธีใช้งานคู่กับ Arduino IDE ใน 3 ขั้นตอน

1

เลือกไฟล์ `.ino`

กดปุ่ม "📂 เปิดไฟล์" ด้านบนเพื่อเลือกไฟล์ที่กำลังเขียนใน Arduino IDE

2

กด Save ใน Arduino IDE

กดปุ่ม "📌 ย่อเกาะจอ" แล้วพิมพ์โค้ดตามปกติ เมื่อกด Ctrl+S โปรแกรมจะตรวจให้ทันที

3

ดูจุดผิด (?) & กดแก้ทันที

ดูเครื่องหมาย ? บนชิ้นส่วนกระดาษแปะ แล้วกดปุ่ม "✨ แก้ทันที" ได้เลย
