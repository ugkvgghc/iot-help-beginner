เขียนโค้ด หรือ หยิบอุปกรณ์ 2D

เลือกไฟล์ .ino จาก Arduino IDE หรือกดปุ่ม "+ หยิบอุปกรณ์ 2D" ด้านล่างเพื่อวางลงบนเบรดบอร์ด

2

ทดลองต่อสายบนเบรดบอร์ด 2D

เอาเมาส์ชี้รูเบรดบอร์ดเพื่อดูแนวไฟเชื่อมกัน และลองกดถอด/เสียบสาย VCC (+) หรือ GND (-) ของอุปกรณ์ได้จริง

3

แก้ Bug & กด ▶️ รันวงจร

ถ้ามีจุดผิด ? กดปุ่ม "✨ แก้ทันที" แล้วกด "▶️ รันวงจร" เพื่อทดสอบไฟกะพริบ ปุ่มกด และเสียง Buzzer!
